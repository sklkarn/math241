To see if the given function is continuous or not needs the following three conditions:
  1. \(f(a)\) is defined.
    🔗
    🔗
  2. \(\displaystyle \lim_{x \to a} f(x) \,\text{ exists. }\)
    🔗
    🔗
  3. The limit equals the function value, i.e.,
    \begin{equation*} \lim_{x \to a} f(x) = f(a)\text{.} \end{equation*}
    🔗
    🔗
If any one fails, \(f\) is discontinuous at \(a\text{.}\)
