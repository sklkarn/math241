In calculus, the derivative of a function \(f(x)\) measures how the function’s output changes as its input changes. In other words, the instantaneous rate of change or the slope of the tangent line to the curve at a point. The derivative is denoted as: \(f'(x)\text{.}\) The first principle (also called the limit definition or difference quotient) is the foundational way to find the derivative by using the formula below.
\begin{equation*} f'(x)=\lim_{h\to 0} \frac{f(x+h)-f(x)}{h} \end{equation*}
However, there is shortcut rules to find the derivative of a function \(f(x).\) If \(y=f(x)\) then,
\begin{equation*} f'(x) = \frac{\,dy}{\,dx} \end{equation*}
