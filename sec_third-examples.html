    Find the derivative of the function given below using first principles (or by the definition of derivative).
    1. \(\displaystyle f(x) = 2x + 5\)

      🔗

      🔗
      🔗
    5. \(\displaystyle f(x)=\frac{1}{x}\)
      🔗

    Example 3.7.11.

    Find an equation of the tangent line to the curve at the given point.
    \begin{equation*} y=1-2x-3x^2, \, (-2,7) \end{equation*}
    🔗
    Solution.
    Using first principle
    \begin{equation*} m =f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h} = \lim_{h \to 0} \frac{f(-2 + h) - f(-2)}{h} \end{equation*}
    \begin{equation*} = \lim_{h \to 0} \frac{[1-2(-2 + h)-3(-2+h)^2] - [1-2(-2)-3(-2)^2}{h} \end{equation*}
    \begin{equation*} = \lim_{h \to 0} \frac{[-7+10h-3h^2] - [-7]}{h} \end{equation*}
    \begin{equation*} = \lim_{h \to 0} \frac{h(10-3h)}{h} = \lim_{h \to 0} (10-3h) =10. \end{equation*}
    Now, equation of tangent line is [(3.0.3)]
    \begin{equation*} y_2-y_1=m(x_2-x_1) \end{equation*}
    \begin{equation*} \therefore \, y-7 = 10(x+2) \end{equation*}
    or
    \begin{equation*} y=10x+13. \end{equation*}

    \(\therefore \, v_{t=2} = -24 \, ft/s.\)

    Example 3.7.16.

    Find an equation of a tangent line to the curve \(y=3x^2-x^3 \) at the point (1,2).
    🔗
    Solution.
    The tangent line at \((1,2)\) has slope \(f'(1)\) and at \(a=1, f(1)=2\text{.}\) Hence from the equation of tangent line
    \begin{equation*} f'(a) = \lim_{x\to a}\frac{f(x) - f(a)}{x-a}. \end{equation*}
    at point (1,2)
    \begin{align*} f'(x) \amp = \lim_{h\to 0}\frac{f(x+h) - f(x)}{h} \\ \amp = \lim_{h\to 0}\frac{[3(x+h)^2-(x+h)^3] - 3x^2+x^3}{h} \\ \amp = \lim_{h\to 0}\frac{[3(x^2+h^2+2xh)-(x^3+h^3 + 3x^2h+3xh^2)] - 3x^2+x^3}{h} \\ \amp = \lim_{h\to 0}\frac{3x^2+3h^2+6xh-x^3-h^3 - 3x^2h-3xh^2 - 3x^2+x^3}{h} \\ \amp = \lim_{h\to 0}\frac{\cancel{3x^2}+3h^2+6xh-\cancel{x^3}-h^3 - 3x^2h-3xh^2 - \cancel{3x^2}+\cancel{x^3}}{h} \\ \amp = \lim_{h\to 0}\frac{(6x-3x^2)h}{h}+ \lim_{h\to 0}\frac{(3h-h^2-3xh)h}{h}\\ \amp = 6x-3x^2\\ \therefore \, f'(1) \amp = 6\times 1-3\times 1^2 = 3. \end{align*}
    or solve \(f'(a) = \lim_{h\to 0}\frac{f(a+h) - f(a)}{h}.\)
    🔗
    Now the equation of tangent line is [(3.0.3)]
    \begin{equation*} y-2 = 3(x-1) \, \Rightarrow \, y = 3x - 1. \end{equation*}

    \begin{equation*} f(x)= \begin{cases} x\sin{\frac{1}{x}} & \text{ if } x \neq 0 \\ 0 & \text{ if } x=0 \end{cases} \end{equation*}

    Hence, the limit \(\lim_{h \to 0} \sin \frac{1}{h}\) does not exist because \(\sin \frac{1}{h}\) oscillates between \(-1\) and \(1.\)

    Example 3.7.18.

    Find the points on the curve \(y=x^4-6x^2+4\) where the tangent line is horizontal.
    🔗
    Solution.
    If tangent line is horizontal then its slope is zero. i.e.,
    \begin{equation*} m = f'(x)= 0 =\frac{dy}{dx}=f'(a) \end{equation*}
    or,
    \begin{align*} f'(x) \amp = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}\\ \amp = \lim_{h \to 0} \frac{[(x+h)^4-6(x+h)^2+4]-(x^4-6x^2+4)}{h}\\ \amp = \lim_{h \to 0} \frac{[(x^4+4x^3h+6x^2h^2+4xh^3+h^4)-6(x^2+2xh+h^2)+4]-x^4+6x^2-4}{h}\\ \amp = \lim_{h \to 0} \frac{x^4+4x^3h+6x^2h^2+4xh^3+h^4-6x^2-12xh-h^2+4-x^4+6x^2-4}{h}\\ \amp = \lim_{h \to 0} \frac{4x^3h+6x^2h^2+4xh^3+h^4-12xh-h^2}{h}\\ \amp = \lim_{h \to 0} \frac{h(4x^3+6x^2h+4xh^2+h^3-12x-h)}{h}\\ or, \, 0 \amp = 4x^3-12x\\ \therefore \, x = a \amp =\pm \sqrt{3} \end{align*}
    🔗
    evaluating at points \((0)\) \(f(0) = 0^4-6\times 0^2+4 =4\) at points \((\sqrt{3})\) \(f(\sqrt{3}) = \sqrt{3}^4-6\times \sqrt{3}^2+4 = 9-18+4=-5\) at points \((-\sqrt{3})\) \(f(-\sqrt{3}) = -\sqrt{3}^4-6\times -\sqrt{3}^2+4 = 9-18+4=-5\)
    🔗
    Hence, The points are \((0, 4)\text{,}\) \((\sqrt{3}, -5)\text{,}\) and \((-\sqrt{3}, -5)\text{.}\)

    Example 3.7.24.

    Find \(a\) so that \(f(x)=\sin x-2(a-1)x\) possess critical point.
    🔗
    Solution.
    \begin{equation*} f(x)=\sin x-2(a-1)x \end{equation*}
    \begin{equation*} f'(x)=\cos x-2(a-1) \end{equation*}
    Now if
    \begin{equation*} \cos x-2(a-1)=0 \end{equation*}
    as \(f'(x)=0\) at critical point. we have -
    \begin{equation*} \cos x=2(a-1) \end{equation*}
    But
    \begin{equation*} -1\leq \cos x\leq 1 \end{equation*}
    \begin{equation*} \therefore \, -1\leq 2(a-1) \leq 1 \end{equation*}
    \begin{equation*} or, \, -\frac{1}{2}\leq (a-1) \leq \frac{1}{2} \end{equation*}
    \begin{equation*} or, \, \frac{1}{2}\leq a \leq \frac{3}{2} \end{equation*}
    Hence, the interval is \([\frac{1}{2}, \frac{1}{2}]\) Point at which \(f'(x) =0\) is called a stationary point.
    🔗
    🔗

    Example 3.7.25.

    \begin{equation*} f'(x) = e^x-e^{-x} =0 \end{equation*}
    \begin{equation*} e^x=e^{-x} = \frac{1}{e^x} \end{equation*}
    \begin{equation*} e^{2x}=1 = e^0 \end{equation*}
    🔗
    or, alternately,
    \begin{equation*} \log {e^{2x}}=2x= \log {1} = 0 \end{equation*}
    \begin{equation*} \Rightarrow \, x=0 \end{equation*}
    Hence the stationary point is \(0,2\) as \(f(x) = 1+1 =2\) at \(x=2.\)
    🔗
    🔗

    Example 3.7.26.

    Prove that \(y = 4x^3-18x^2+27 x-7\) has no extremum.
    🔗
    Solution.
    \begin{equation*} f(x) = 4x^3-18x^2+27 x-7 \end{equation*}
    \begin{equation*} f'(x) = 12x^2+-36x+27= 3(2x-3)(2x-3) =0 \end{equation*}
    \begin{equation*} \therefore \, x = \frac{3}{2} \end{equation*}
    At \(x = \frac{3}{2},\) \(f'(x) \) gives zero value but its graph is increasing continuously. Hence, \(x = \frac{3}{2}\) does not give any extremum point.
    🔗
    Here \(f'(x)\) is not changing sign, so there is no maxima and minima.
